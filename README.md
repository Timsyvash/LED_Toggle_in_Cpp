# LED Toggle in C++ (ESP8266 Web Server)

Проєкт для керування вбудованим світлодіодом мікроконтролера **ESP8266 (Wemos D1 mini)** через простий HTTP вебсервер у локальній мережі.

---

## 🛠 Технології та Бібліотеки

* **Платформа:** ESP8266 (Arduino / PlatformIO)
* **Мережевий стек:** `ESP8266WiFi` (режим STA)
* **Вебсервер:** `ESP8266WebServer` (обробка HTTP GET запитів)
* **Апаратна частина:** Вбудований світлодіод (пін `D4` / `LED_BUILTIN`)

---

## 📌 Підключення та Пінкод

* Використовується стандартний вбудований світлодіод на піні **D4** (GPIO2) плати Wemos D1 mini.
* Плата підключається до домашнього Wi-Fi роутера у режимі клієнта (Station).

---
